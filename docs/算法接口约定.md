# ReID 引擎接口约定（给算法组）

> 系统线与算法线的唯一交汇点。你只需要按本文档交付两个文件，系统侧一行代码不用改，检索界面、demo、测试全部自动用上你的新模型。

## 一、你交付什么

| 交付物 | 说明 |
|---|---|
| `engine.py` | 你的模型定义 + `ReIDEngine` 类（见下方接口规范） |
| `xxx.pth` | 你训好的权重文件 |
| `requirements.txt` | 你引擎额外需要的 pip 依赖（如 `clip`、`timm` 等），逐行列出 |

**不要做的事**：
- 不要改动系统其他任何文件（`search.py` / `demo.py` / `app.py` 等）
- 不要把代码放进 `fast-reid/` 目录（第三方源码只读）
- 不需要关心 Flask、YOLO、视频流——那些是系统线的事

## 二、接口规范

系统侧唯一调用的形式：

```python
from engine import ReIDEngine

engine = ReIDEngine(weights_path="weights/你的权重.pth")
feat = engine.extract(img_bgr)
```

### `ReIDEngine` 类必须实现

```python
class ReIDEngine:
    """ReID 特征提取引擎。"""

    def __init__(self, weights_path: str, device: str = "cpu"):
        """
        加载模型和权重。
        :param weights_path: 权重文件路径
        :param device: "cpu" 或 "cuda:0"，系统会按运行环境传入
        """

    def extract(self, img_bgr: "np.ndarray") -> "np.ndarray":
        """
        输入一张行人小图，输出特征向量。
        :param img_bgr: BGR 格式图像，shape=(H, W, 3)，uint8（OpenCV 默认读出的格式）
        :return: 一维特征向量，shape=(D,)，float32，且已做 L2 归一化（模长=1）
        """
```

**硬性要求（缺一不可）**：
1. 输出是**一维**向量（不是 (1, D) 的二维数组）
2. 已做 **L2 归一化**——系统用余弦相似度排序，没归一化会导致相似度全错
3. 输入图像来自 YOLO 裁剪或数据集原图，**尺寸不保证**，引擎内部自己 resize
4. 同一张图多次调用 `extract` 结果必须一致（推理阶段固定 eval 模式）

### 换衣双分支模型的额外约定

如果模型有服饰/结构两个分支、输出两组特征，再额外提供一个融合函数：

```python
def fuse(feat_a: "np.ndarray", feat_b: "np.ndarray") -> "np.ndarray":
    """把两支特征融合为一个向量，返回 L2 归一化后的一维向量。"""
```

并在交付说明里注明两支的调用顺序（哪支是服饰、哪支是结构）。系统在比对前会调用它融合。

## 三、参考实现（当前旧引擎的样子）

`extractor.py` 里的 `ReIDExtractor` 就是按这个接口写的（FastReID R50），核心流程供参考：

```
读图 → resize(256,128) → 转张量[0,255] RGB → 模型前向 → 取特征 → L2 归一化
```

## 四、交付前自测清单

在**你自己的环境**里跑通这段，通过了再交付：

```python
import cv2, numpy as np
from engine import ReIDEngine

engine = ReIDEngine("weights/你的权重.pth")
img = cv2.imread("任意一张行人图.jpg")          # BGR, uint8
feat = engine.extract(img)
assert feat.ndim == 1                            # 一维
assert abs(np.linalg.norm(feat) - 1) < 1e-5      # L2 归一化
assert engine.extract(img) 接近 feat             # 结果稳定
```
